Сценарий тестирования — Progressors Learning Bot

Бот: @progressors_learn_bot  ·  True Tech Arena 2026  ·  Открыть: /start → кнопка «🚀 Открыть приложение»

Сценарий 1 — IT Backend (основной, ~5 минут)

1. Запуск

  1. Найти бота @progressors_learn_bot в Telegram
  2. Нажать /start
  3. Нажать кнопку 🚀 Открыть приложение — Mini App откроется внутри Telegram

2. Онбординг и диагностика

  1. Выбрать сферу: IT → Backend-разработка
  2. Пройти 7 вопросов диагностического квиза — отвечать своими словами, можно кратко
  3. ИИ (Groq llama-3.3-70b) оценивает ответы семантически — понимает суть, а не точное совпадение слов
  4. Выбрать форматы обучения (например, Видео)
  5. Система определит уровень: Новичок / Средний / Продвинутый

3. Работа с маршрутом

  1. Открыть Шаг 1 — «Основы Python»
  2. Нажать ▶ Смотреть на видео — YouTube-плеер запускается прямо внутри приложения
  3. Нажать кнопку 📖 Документация — открываются шпаргалки по Python/Django/FastAPI через Telegram Instant View
  4. Нажать 📚 Хочу больше материалов → выбрать формат → ИИ подбирает из базы 273 ресурсов

4. Квиз и корректировка курса

  1. Пройти квиз по шагу, намеренно допустить 2–3 ошибки
  2. Нажать «🎯 Откорректировать курс»
  3. ИИ анализирует конкретные ошибки пользователя и выдаёт уникальный персональный совет

5. Следующий шаг

  1. Нажать ✅ Завершить шаг
  2. Убедиться: Шаг 2 «ООП» содержит другие материалы — повторений нет
  3. Сменить сферу → вернуться обратно → прогресс и пройденные шаги сохранены

Сценарий 2 — Персонализация (~3 минуты)

  1. Начать заново → выбрать IT → Machine Learning
  2. Пройти квиз с развёрнутыми, грамотными ответами → система определит уровень Средний или Продвинутый
  3. Запустить ещё раз, отвечать кратко или не по теме → уровень Новичок, маршрут другой
Один пользователь, одна сфера, разные знания — разные маршруты. Демонстрирует настоящую персонализацию.

Ключевые сильные стороны решения

Видео внутри приложения YouTube-плеер встроен — ничего не открывается в браузере
Семантический квиз «нейронные слои» засчитывается как правильный ответ про ИИ
273 проверенных ресурса Прямые ссылки, только бесплатное, только на русском
Документация в Telegram Шпаргалки по языкам через Telegram Instant View — не уходит из приложения
Уникальный AI-совет Groq анализирует конкретные ошибки, не шаблонный текст
Прогресс не теряется Смена сферы и возврат — всё сохраняется
